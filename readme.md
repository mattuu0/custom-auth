# authbase

このリポジトリは、Go言語で構築された堅牢でスケーラブルな認証基盤「authbase」のバックエンドAPIです。メールアドレス/パスワード認証とソーシャルログイン（OAuth 2.0）の両方をサポートし、JWTとリフレッシュトークンを用いた安全なセッション管理を提供します。

## 目的

一般消費者向けWebサービスのスケーラブルな認証システムを、ゼロから構築することを目的としています。セキュリティ、パフォーマンス、メンテナンス性を重視した設計になっています。

## 技術スタック

  * **言語**: Go
  * **フレームワーク**: Echo
  * **データベース**: PostgreSQL
  * **ORM**: Gorm
  * **リバースプロキシ**: Nginx (HTTPS化, レートリミット)

## 主な機能

  * **ユーザー認証**:
      - メールアドレスとパスワードによる認証
      - Googleなどのソーシャルログイン（OAuth 2.0）
  * **アカウント管理**:
      - 新規ユーザー登録（メール認証フローを含む）
      - パスワードのリセット
  * **セッション管理**:
      - JWTによるセッショントークン
      - リフレッシュトークンによるセッショントークンの更新
  * **セキュリティ**:
      - パスワードの強力なハッシュ化 (`bcrypt`)
      - レートリミットによる不正アクセス対策
      - HTTPSの強制

## セットアップ

### 開発環境の起動
アプリケーションは、\*\*`http://localhost:8922`\*\*で起動します。

Nginxをリバースプロキシとして前段に配置することで、**`https://your_domain.com/auth/`** のようにアクセスできるようになります。
